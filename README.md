# oazis-sync-bot

Telegram-бот, который переносит новые материалы из рабочих групп в общую группу по проектам.

- `sync.py` — логика переноса (long polling, работает без перерывов ~5,5 ч, затем перезапускается).
- `data.enc` — настройки и состояние, зашифрованы (AES-256). Ключ хранится только в секретах репозитория.
- `secure.sh` — распаковка/упаковка `data.enc`.
- `.github/workflows/sync.yml` — непрерывная работа в GitHub Actions + часовая страховка.

Токены в репозитории не хранятся.
